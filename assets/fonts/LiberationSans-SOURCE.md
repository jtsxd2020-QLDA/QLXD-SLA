# Liberation Sans 2.1.5

Unmodified `LiberationSans-Regular.ttf` from the official Liberation Fonts 2.1.5 release. Redistributed under the SIL Open Font License 1.1 in `LiberationSans-OFL.txt`.

- Upstream: https://github.com/liberationfonts/liberation-fonts
- Release: https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5
- Binary archive linked from upstream release: https://github.com/liberationfonts/liberation-fonts/files/7261482/liberation-fonts-ttf-2.1.5.tar.gz
- Archive SHA256: `7191c669bf38899f73a2094ed00f7b800553364f90e2637010a69c0e268f25d0` (also matched Homebrew font-liberation cask).

Used for Vietnamese PDF reports because this static font preserves precomposed Vietnamese characters in PDFKit's glyph-to-Unicode mappings. Defaults remain enabled: no combining-feature/CMap patch is applied.
